# ShoeStore Landing Page

A shoe store landing page built with HTML and CSS.

## About

A simple shoe store landing page created while learning and practicing Flexbox, layout, spacing, and basic UI styling.

## Technologies

- HTML5
- CSS3

## Concepts Practiced

- Flexbox
- Flex containers
- Flexbox alignment
- Gap and spacing
- Nested Flexbox
- Basic layout
- Buttons and links
- Pseudo-classes
